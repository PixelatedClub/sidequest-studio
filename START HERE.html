Sidequest Studio

Create a solo adventure, send it to a player, and review their recap.

Open Sidequest Studio

This is a portable browser app. There is no installer. No account, Terminal commands or administrator access is required.

Open on a Mac

  1. Save Sidequest-Studio.zip from the message.
  2. Double-click the ZIP in Finder to extract it.
  3. Move the extracted folder somewhere you want to keep it, such as Documents.
  4. Control-click Sidequest Studio.html, choose Open With, then Safari, Chrome or Edge.
  5. Keep using the same file and browser for local saves. Ignore the Windows .cmd shortcut.

Apple’s instructions for choosing an app to open a file

Open on Windows

Save the ZIP, right-click it and choose Extract All. Open Sidequest Studio.html with Chrome or Edge. Open Sidequest.cmd is an optional shortcut. Extract the files before using the editor.

Create an adventure

  1. Select DM mode. The first launch shows an 18-scene placeholder example. New or Start blank creates an empty adventure.
  2. Open Adventure details to enter a title and player instructions.
  3. Add scene text and optional images. Add choices and link them to other scenes.
  4. Choose D20 ability check for success/failure branches, or Random event table for a die with event ranges.
  5. Mark final scenes as endings. Use Check adventure to find missing links.
  6. Test with the preview or Player mode. Examples are optional placeholders.
  7. Select Export player adventure to create one playable HTML file.

Autosave and the Library use this browser’s storage. They do not automatically create backup files or sync between devices. Export project backups before clearing browser data, moving files or changing browsers. Do not use private browsing for saves you want to keep. The creator’s localhost link will not work on someone else’s computer.

Player instructions

Open the exported HTML in a browser. Read each scene, choose an action, and roll in the app or enter your physical die result when prompted. Use the notes section for dialogue, decisions or questions. At the end, download a recap and send it to your DM.

Replay starts a new run and keeps the previous recap under Previous runs, up to 20. Download any recaps you want to keep outside this browser.

What has been tested?

The distributed ZIP was extracted into a separate test folder. Its editor and exported adventures passed tests for saving, reopening, library use, dice checks, recap downloads and replay with WebKit on Windows, as well as Chromium. WebKit is Safari’s browser engine.

A real Mac has not been tested. These checks do not verify macOS Finder, actual Safari settings, or your messaging service’s attachment rules. This is a browser app, not a native macOS installer.

Full instructions and feature reference

Keep DM project files private. Exported player adventures exclude DM notes. Switching modes in the editor is not password protection.
